# Q1 canonical project identity

Q1 is an open-source protocol project initiated by Yousef Bahrami, who maintains
the project. This document identifies the maintainer's distribution channels;
it makes no claim to ownership of a network or of third-party implementations.

## Canonical channels

- Official source repository: [YousefBahrami/Q1](https://github.com/YousefBahrami/Q1).
- Official release index: [Q1 releases](https://github.com/YousefBahrami/Q1/releases).
- Current published version: [v0.1.0-localnet.1](https://github.com/YousefBahrami/Q1/releases/tag/v0.1.0-localnet.1),
  **Q1 LOCALNET v0 — Experimental**.
- Public project status: README and PROJECT on that repository's `main` branch.
- Non-sensitive technical contact: the canonical repository's issues and pull requests.
  No dedicated project email or private security intake has been established by
  this phase; follow SECURITY.md for the current reporting limitation.

No separate official website, company, foundation, issuer, public network,
token offering or exchange listing is announced by these channels. Future
channel changes should be cross-linked from the existing canonical repository.

## Project name and third-party implementations

In these documents, **Q1 project** identifies this maintained upstream project.
**Q1 protocol** identifies the specified, versioned rules, currently implemented
only in the LOCALNET profile. **Official Q1 release** means a version designated
by the maintainer in the canonical release index. None of those terms means
that a deployed public-value network exists.

A third-party fork can identify its Q1 origin and document compatibility. For
clarity, use its own distribution name and state the upstream version, changes,
operator and support channel. Suggested wording:

> Independent fork based on Q1 v0.1.0-localnet.1. Maintained separately; this is
> not an official release of the upstream Q1 project.

Passing Q1 vectors is compatibility evidence for the cases tested, not automatic
endorsement, security certification or authority over official releases. A copied
name, logo, ChainId or GenesisId alone does not authenticate a distribution.
