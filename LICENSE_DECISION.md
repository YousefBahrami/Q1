# Q1 license decision — DEC-Q1-015

Status: APPROVED, 2026-10-02
Decision: Apache-2.0, explicitly selected by the project owner during release
candidate preparation. The authoritative text is in [LICENSE](LICENSE).
This supersedes the previous no-license placeholder. No remote publication is
implied by license approval. Dependencies retain their own licenses.

| Option | Type / patents | Modified hosted services | Compatibility / Q1 fit |
|---|---|---|---|
| Apache-2.0 | Permissive; express contributor patent grant and litigation termination | Hosting alone does not require a source offer | Broad implementation reuse; GPLv3-compatible, not GPLv2-only |
| MIT | Permissive; no express patent-grant clause | No hosting source requirement | Simple reuse, including closed derivatives |
| GPL-3.0 | Strong copyleft; explicit contributor patent terms | Hosting alone is not conveying | Distributed covered derivatives stay open; combined proprietary works constrained |
| AGPL-3.0 | Strong copyleft plus network condition; patent terms | Modified versions offer corresponding source to remote users | Keeps service modifications available; more restrictive integration |
