# Q1 Architecture Decision Records

This is the canonical ADR directory. The former root-level `ADR/` path is
retired.

No ADR is approved merely because a draft exists.

## Status values

- Proposed
- Ready for Decision
- Accepted
- Rejected
- Superseded
- Deprecated

`Ready for Decision` means the analysis is sufficiently complete for human
review. It does not approve the recommendation.

Only the human decision-maker may approve an ADR or change it to `Accepted`.

## Required fields

Each ADR must record:

- Title
- Status
- Date
- Decision owner
- Related decisions and requirements
- Context
- Decision
- Alternatives
- Consequences
- Security impact
- Test impact
- Migration impact
- Open questions
- Approval record

Rejected and superseded ADRs remain in the repository for traceability.
