# Pre-offer engineering boundary

Status: factual scope of the public source milestone, 2026-10-02.

- Public source code does not equal a public token offering. This milestone
  publishes source, tests and reproducibility artifacts.
- LOCALNET units have no represented monetary value. Fixture balances and
  public test keys are solely for technical evaluation.
- Mainnet issuance and economics are not finalized. LOCALNET fee=1 and its
  conserved test supply are not final monetary policy.
- No token sale, pricing, trading/exchange integration or monetary distribution
  is authorized by this repository milestone.
- Legal/compliance review must precede any proposed public-value launch.

This document states engineering boundaries. It provides no legal conclusion
and makes no claim of regulatory compliance. The source license remains
[Apache-2.0](../../LICENSE); licensing source code is separate from authorizing
an operated network or public-value activity.
