# Q1 v0.1.0-localnet.1 — release candidate

Scope: LOCALNET_V0 ONLY. Experimental, no monetary value, not Mainnet, no
production-security or decentralization claim. License: Apache-2.0, explicitly
approved for DEC-Q1-015 on 2026-10-02. No remote release or tag has been created.

## Included

- Strictly signed transfers; actual fee exactly 1 base unit, FeeLimit a ceiling.
- Explicit reward pool, zero issuance/burn/distribution and conserved total supply.
- Canonical full StateRoot covering balances, nonces, reward pool and authority.
- Signed proposals, attestations and certificates under the registered domains.
- One fixed non-voting producer and three fixed voters, quorum 2-of-3, round zero.
- Atomic block rejection, durable archive commit and authenticated history replay.
- Durable anti-equivocation reservations, restart and voter catch-up.
- Real four-process acceptance with a killed voter, continued progress and equal roots.
- Foreground localnet console, local test wallet creation and signed-transfer CLI.
- Frozen vectors, independent checks, reproducible source snapshot and checksums.

## Reproduce

From the received source root, run `python3 scripts/check_all.py`.
For manual operation follow README.md; all CLI examples are exercised by the
release checks. The accepted protocol milestone is `0c177fd`; the candidate
retains its exact frozen protocol vectors and final acceptance StateRoot.

## Deferred / non-production

Mainnet consensus parameters; producer failover/rotation; final economics;
production delay; admission/validator rules; public networking hardening;
production wallet custody; partial state proofs; efficient/pruned storage;
a complete independent security audit. No public network is launched.

## Distribution boundary

Release artifacts are source-only, include LICENSE and reference evidence, and
exclude build output, local wallets/databases, personal YOS context and Git
history. Protocol material and historical evidence remain in the source;
old machine paths are rendered portably. The original repository/history is
retained privately and must not be pushed as the public candidate. A fresh
public repository may later be initialized from the reviewed snapshot only
with explicit publication authorization. Archive names and SHA-256 manifests
identify exact source commits; no tag is needed to reproduce them.
